# Changelog

## v5

- Added direct vector PDF generation from processed DXF.
- Added PDF Optional Content Groups (layers).
- Added searchable PDF text with Cyrillic support through Arial on Windows.
- Preserved DXF layer generation from electrical-line labels.
- Preserved automatic `Color 255` → `ByLayer` normalization.
- Preserved CSV mapping output.
- Preserved interactive HTML/SVG viewer.
- Preserved desktop click selection and mobile pinch-to-zoom / zoom buttons.

## v4

- Improved desktop and mobile interaction in the HTML viewer.
- Fixed desktop click selection of electrical lines.
- Added / refined mobile zoom and touch behavior.

## Earlier prototype iterations

- Automatic recognition of electrical-line blocks by structure.
- Layer creation from repeated text labels inside blocks.
- Arial text normalization.
- CSV report generation.
- Interactive HTML/SVG prototype.
