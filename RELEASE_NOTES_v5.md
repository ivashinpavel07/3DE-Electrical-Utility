# 3DE Electrical Utility v5

Experimental Windows utility for processing DXF electrical logical schematics exported from CATIA 3DEXPERIENCE.

### v5 highlights

- Automatic DXF layers based on electrical-line designations.
- `Color 255` → `ByLayer` for electrical-line geometry.
- Arial text normalization.
- CSV mapping report.
- Interactive HTML/SVG viewer with search and highlighting.
- Vector PDF with PDF layers and searchable text.
- Batch selection of DXF files through the GUI.

### Important

This is an experimental build. Please validate generated DXF/PDF/HTML files against the source schematic, especially when testing DXF exports from other projects or 3DEXPERIENCE configurations.

### Windows binary

Download `3DE_Electrical_Utility_v5.zip` from the Assets section below, extract it, and run `3DE_Electrical_Utility_v5.exe`.

Python is not required for end users of the prebuilt EXE.
